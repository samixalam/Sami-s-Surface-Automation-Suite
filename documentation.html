Sami's Surface Automation Suite

A unified diagnostic and preparation toolkit for Microsoft Surface inventory.

Revision 1.2 | Developed by Sami

Project Overview

This automation suite was designed by Sami to standardize the processing of diverse Surface models. By utilizing a Smart Dispatcher Architecture, the toolkit identifies the device's age and security restrictions to execute the correct diagnostic environment.

Sami's Smart Logic (V1.2):
• Legacy Path: Optimized for Surface RT (1516). Bypasses "Constrained Language Mode".
• Modern Path: Optimized for Pro/Laptop/Go. Uses high-speed CIM Instances.

1. The Smart Audit Phase

Automatically captures Serial Numbers, Specs, and calculates Battery Health Percentage without manual math.

Step 1: Enter Audit Mode using Ctrl + Shift + F3.
Step 2: Connect the USB and launch Run_Audit.bat.
Step 3: Review the automated folder created in the /Reports directory.

Note: All data is stored in a dedicated folder named [Model]_[Serial] to prevent inventory mix-ups.

2. The Camera User Loop

Automates the transition between system modes to verify hardware functionality.

Step 1: Run Scripts/Camera_Prep.bat to reboot into OOBE.
Step 2: Create local account CameraTest and verify front/rear sensors.
Step 3: Reboot and return to Audit Mode using Ctrl + Shift + F3 at the sign-in screen.

3. Data Wipe & Resale Shipment

Ensures 100% data destruction and prepares the device for the end-buyer.

Step 1: Run Run_Camera_Cleanup.bat. This nukes the test profile and images.
Step 2: Run Run_Final_Ship.bat. This clears event logs and triggers the final Sysprep shutdown.
Compliance: Do not hand off a device unless it has been shut down via Sami's Final Ship tool. This ensures the customer receives a "New Device" setup experience.

Technical Support & Troubleshooting

Observation Resolution
"Constrained Language" Error The dispatcher (Run_Audit) automatically handles this by calling the Legacy script.
Battery "Check HTML" Common on RT 1516 models. Refer to the Battery_Report.html in the device folder.
Sysprep Failure Ensure no Windows Updates are pending. Restart once and retry the script.

Sami's Command Reference

Core logic utilized by the toolkit for technical documentation:

  • Architecture Scout: ver (Batch version detection)
  • Legacy Battery: root/wmi/BatteryFullChargedCapacity
  • Modern Driver Scan: Get-PnpDevice
  • OOBE Finalization: sysprep.exe /oobe /shutdown
